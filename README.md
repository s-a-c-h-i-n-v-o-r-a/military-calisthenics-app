# Military Calisthenics Daily App

Daily 30-min bodyweight workout tracker for iPhone (Safari + Add to Home Screen).

## Setup for GitHub Pages
1. Download the fitness-app.zip from the chat (or recreate the folder with index.html + the .jpg images).
2. On github.com, open this repo, click "Add file" → "Upload files", drag the entire contents of the unzipped fitness-app folder (index.html and all .jpg files) into the root, commit.
3. Go to Settings → Pages → Source: Deploy from a branch → Branch: main, Folder: / (root) → Save.
4. Wait 1–2 minutes. Open: https://s-a-c-h-i-n-v-o-r-a.github.io/military-calisthenics-app/
5. On iPhone Safari: Share → Add to Home Screen. Full timers, tracker, and images will work. Logs stay local on the phone.

Repo is ready. Just upload the files and enable Pages.
